# Wiktionary data attribution

This data directory contains Vietnamese gloss overrides derived from English Wiktionary entries.

The source material is from the official English Wiktionary project and is available under the **Creative Commons Attribution-ShareAlike 4.0 International License (CC BY-SA 4.0)** and the **GNU Free Documentation License (GFDL)**. Wiktionary source pages are recorded per override in `general_translation_overrides.tsv`.

Source project: <https://en.wiktionary.org/>
Official dump index: <https://dumps.wikimedia.org/enwiktionary/>
Dump/reference date used for the extraction: August 2026 (`latest` index published 05-Aug-2026).
License text: <https://creativecommons.org/licenses/by-sa/4.0/deed.en> and <https://www.gnu.org/licenses/fdl-1.3.html>

Changes made for Word Wise: entries were selected from Wiktionary's English sections, Vietnamese translation templates were extracted, wiki markup and non-Vietnamese alternatives were filtered, and the selected gloss was associated with the existing Word Wise English short gloss. No new Vietnamese translation text was generated by the extraction pipeline. The resulting data is a curated/adapted selection and must retain attribution and applicable ShareAlike/transparent-copy obligations.

Wiktionary pages can contain externally sourced material with different terms. Only the selected Vietnamese translation template strings and their source-page links are used here; candidates that contained unresolved markup, non-Vietnamese characters, ambiguous sense matches, or malformed data remain outside the release database.

This notice is technical attribution documentation, not formal legal advice. Review the final distribution terms before publishing a bundle containing adapted Wiktionary text.
